# Starter templates

Copy-ready files from the **GitHub skills** track. Copy a file into your own repo at the path shown at the top of each one, then edit the placeholders.

| File | Goes in your repo at | Lesson |
|------|---------------------|--------|
| [ci.yml](ci.yml) | `.github/workflows/ci.yml` | [GitHub 4: Actions](../lessons/github/04-actions.md) |
| [bug-report.yml](bug-report.yml) | `.github/ISSUE_TEMPLATE/bug-report.yml` | [GitHub 2: Issues and Projects](../lessons/github/02-issues-and-projects.md) |
| [feature-request.yml](feature-request.yml) | `.github/ISSUE_TEMPLATE/feature-request.yml` | [GitHub 2: Issues and Projects](../lessons/github/02-issues-and-projects.md) |
| [PULL_REQUEST_TEMPLATE.md](PULL_REQUEST_TEMPLATE.md) | `.github/PULL_REQUEST_TEMPLATE.md` | [GitHub 3: Code review](../lessons/github/03-code-review.md) |
| [CODEOWNERS](CODEOWNERS) | `.github/CODEOWNERS` | [GitHub 3: Code review](../lessons/github/03-code-review.md) |
| [release.yml](release.yml) | `.github/release.yml` | [GitHub 5: Releases](../lessons/github/05-releases.md) |
| [dependabot.yml](dependabot.yml) | `.github/dependabot.yml` | [GitHub 6: Security](../lessons/github/06-security.md) |
| [SECURITY.md](SECURITY.md) | `SECURITY.md` | [GitHub 6: Security](../lessons/github/06-security.md) |

They're deliberately in `templates/`, not `.github/`, so they don't affect this repo.
