# Security policy

## Reporting a vulnerability

Please **don't** open a public issue for security problems, for example in the workflows, the scripts or the website's badge checker.

Report it privately instead:
- Use **Security → Report a vulnerability** on this repository, or
- Email **info@jeremyanderson.tech**

Include what you found and how to reproduce it. You'll get a reply within 3 business days.

## Scope

This repo is documentation, two small shell scripts, a static website and GitHub Actions workflows. It stores no user data. The website's badge checker calls GitHub's public API directly from your browser.
