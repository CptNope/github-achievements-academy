# Lesson 8: Highlights & retired badges 🏅

## Highlights (status badges)

Some badges reflect a **status** rather than an achievement. They appear in the *Highlights* area of your profile and can disappear if the status ends.

| Highlight | How you get it |
|-----------|----------------|
| **PRO** | Have a paid GitHub Pro plan |
| **Developer Program Member** | Join the [GitHub Developer Program](https://docs.github.com/en/get-started/exploring-integrations/github-developer-program) |
| **Security Bug Bounty Hunter** | Have a valid report accepted through the [GitHub Security Bug Bounty](https://bounty.github.com/) |
| **GitHub Campus Expert** | Be accepted into GitHub's student leadership program |
| **Security advisory credit** | Be credited on a reviewed advisory in the GitHub Advisory Database |

> These change from time to time. If something here is out of date, please open a PR!
