# Start here

Welcome. This academy teaches Git and GitHub from scratch, all the way to running real projects, and earns you every obtainable GitHub achievement honestly along the way. It's free, and you need nothing but a browser to begin.

There are **four tracks** and a set of guides. You don't have to do them all in order. Find the path that matches you below.

## Pick your path

### I've never used Git or GitHub
About 4 to 6 hours, spread over a few days.
1. [Lesson 0: Setup](00-setup.md). Choose the website-only route if you'd like to avoid the command line for now.
2. [Git 1: How Git actually works](git/01-how-git-works.md) and [Git 2: The everyday loop](git/02-everyday-loop.md)
3. The badge lessons, [Lesson 1](01-quickdraw.md) to [Lesson 3](03-pull-shark.md). You'll make your first real contribution to this repo.
4. The rest of the [Git fundamentals](git/03-branching-and-merging.md) track, practicing in the [sandbox](https://cptnope.github.io/github-achievements-academy/sandbox/)
5. Then pick up the other badges and the GitHub skills track at your own pace

### I use Git, but I'm new to collaborating on GitHub
About 3 hours.
1. Skim [Lesson 0](00-setup.md), then do [Lessons 1 to 5](01-quickdraw.md) for the badges
2. [GitHub 1: Your profile](github/01-profile.md) to [GitHub 3: Code review](github/03-code-review.md)
3. [GitHub 7: Contributing to open source](github/07-open-source.md)
4. Bookmark the [Oh no! guide](oh-no.md)

### I want to work like a professional team
About 3 hours.
1. [Git 4: Rebase](git/04-rebase.md) and [Git 5: Remotes](git/05-remotes.md)
2. [GitHub 3: Code review](github/03-code-review.md) to [GitHub 6: Security](github/06-security.md)
3. [Repo 1: Foundations](repos/01-foundations.md), [Repo 5: Team and client projects](repos/05-team-and-client-projects.md) and [Repo 8: Maintaining](repos/08-maintaining.md)

### I build WordPress plugins or themes
About 2 hours.
1. [Repo 1: Foundations](repos/01-foundations.md) and [Repo 6: WordPress plugins and themes](repos/06-wordpress-plugins.md)
2. [GitHub 4: Actions](github/04-actions.md), [GitHub 5: Releases](github/05-releases.md) and [GitHub 6: Security](github/06-security.md)

### I teach, or run workshops
1. [Repo 7: Courses, workshops and templates](repos/07-courses-and-templates.md)
2. The [badges track](00-setup.md), which works well as a first-week activity
3. Send learners to the [sandbox](https://cptnope.github.io/github-achievements-academy/sandbox/) to practice safely

### Something's broken right now
Go straight to [Oh no! Undo any Git mistake](oh-no.md). Find your situation and copy the fix.

## How each lesson works

- **Read, then do.** Every lesson ends with an exercise in your own sandbox repo, never in someone else's project.
- **Quiz.** Three questions at the end check what stuck. A perfect score marks the lesson complete.
- **Progress** is saved in your browser only. There's no account and no tracking. Your progress bars are on the [lessons page](https://cptnope.github.io/github-achievements-academy/learn/).
- **Badges are earned honestly.** Read [Fair play](../FAIR-PLAY.md) once before you start. It explains what GitHub's rules allow.

## Words you'll meet early

| Word | Meaning |
|------|---------|
| **Repository (repo)** | A project's folder plus its full history |
| **Commit** | A saved snapshot of your project, with a message saying why |
| **Branch** | A separate line of work. It's just a label on a commit |
| **Clone** | A full copy of a repo on your computer |
| **Fork** | Your own copy of someone else's repo, on GitHub |
| **Pull request (PR)** | A request to merge your branch's changes into another branch |
| **Merge** | Combining the work from one branch into another |
| **Issue** | A bug report, idea or task, tracked on GitHub |

The [cheat sheet](cheat-sheet.md#glossary) has the full glossary.
