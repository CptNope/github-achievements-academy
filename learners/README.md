# 🧱 Learners Wall

Everyone here is learning GitHub in public. Each file is one learner's progress page.

**Want to join?** Follow [Lesson 3: Pull Shark](../lessons/03-pull-shark.md) and [CONTRIBUTING.md](../CONTRIBUTING.md).

Rules, checked automatically on every pull request:
1. Your file must be named `learners/<your-github-username>.md` (lowercase).
2. A PR may only add or change **your own** file.
3. Keep the three template headings: `About me`, `Lessons completed`, `What I learned`.
4. Keep it under 4 KB, with at most 3 links. No star/follow requests.
