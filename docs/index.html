Badges as lessons

Farming scripts open a thousand empty pull requests. Here every GitHub badge is a lesson instead: you learn the real skill, and the badge is your certificate.

Who it's for. Anyone new to GitHub, from students to career changers, plus developers who have always done solo work and never sent a pull request to someone else's project.

What you learn. Issue triage, the branch and pull request flow, forks and upstreams, code review, co-authored commits, answering questions well, and shipping a project that people want to star.

Where it happens. On GitHub itself. Lessons 1 and 2 run in a sandbox repo you own, and lesson 3 runs right here, on the Learners Wall, where a person reviews every pull request.

How to join. Read lesson 0, fork the repo and add your own page to the Learners Wall. It's free, it needs no sign-up beyond your GitHub account, and nothing here asks you for stars.

Farmed or earned

GitHub's Acceptable Use Policies ban automated bulk activity, fake accounts and automated starring. A badge isn't worth your account, especially if your work and portfolio live there. So nothing in this course loops, fakes an interaction or trades stars.

Questions people ask

Can I get banned for chasing badges?
Not for normal activity. The risk comes from bulk automation, alternate accounts, and buying or trading stars, all of which GitHub's Acceptable Use Policies prohibit. Everything in this course is one real action at a time. Read the fair-play guide.
I did the lesson but the badge never appeared.
Give it up to 24 hours, then check that your commit email is verified on your account, and that the work was merged into the default branch of the parent repo. Commits that stay in a fork don't count. Full troubleshooting list.
Do private repositories count?
Only if you turn on private contributions in your profile settings. They then show up as anonymous counts, so nobody sees the repo names.
Do I need the command line?
No. Every lesson can be done on github.com. The optional coach script uses the GitHub CLI, explains each command before it runs, and asks for your OK at every step.
Can I still get Arctic Code Vault or Mars 2020?
No. Both are retired and can't be earned anymore, so ignore anyone selling a method. Lesson 8 lists what's retired or was never released.
I broke something in Git. Help?
Breathe. Git almost never loses committed work. The Oh no! guide has copy-and-paste fixes for the common disasters, from a bad commit message to a leaked API key.
Is this made by GitHub?
No. It's an independent, open-source project by Jeremy Anderson Tech. Corrections are welcome as pull requests, and every fix you send counts toward Pull Shark.

How close are you?

This uses GitHub's public API from your browser, so your username stays between you and GitHub. Counts are estimates. Your profile's Achievements tab is the final word.
