Start here

Welcome. This academy teaches Git and GitHub from scratch, all the way to running real projects, and earns you every obtainable GitHub achievement honestly along the way. It's free, and you need nothing but a browser to begin.

There are four tracks and a set of guides. You don't have to do them all in order. Find the path that matches you below.

Pick your path

I've never used Git or GitHub

About 4 to 6 hours, spread over a few days.

  1. Lesson 0: Setup. Choose the website-only route if you'd like to avoid the command line for now.
  2. Git 1: How Git actually works and Git 2: The everyday loop
  3. The badge lessons, Lesson 1 to Lesson 3. You'll make your first real contribution to this repo.
  4. The rest of the Git fundamentals track, practicing in the sandbox
  5. Then pick up the other badges and the GitHub skills track at your own pace

I use Git, but I'm new to collaborating on GitHub

About 3 hours.

  1. Skim Lesson 0, then do Lessons 1 to 5 for the badges
  2. GitHub 1: Your profile to GitHub 3: Code review
  3. GitHub 7: Contributing to open source
  4. Bookmark the Oh no! guide

I want to work like a professional team

About 3 hours.

  1. Git 4: Rebase and Git 5: Remotes
  2. GitHub 3: Code review to GitHub 6: Security
  3. Repo 1: Foundations, Repo 5: Team and client projects and Repo 8: Maintaining

I build WordPress plugins or themes

About 2 hours.

  1. Repo 1: Foundations and Repo 6: WordPress plugins and themes
  2. GitHub 4: Actions, GitHub 5: Releases and GitHub 6: Security

I teach, or run workshops

  1. Repo 7: Courses, workshops and templates
  2. The badges track, which works well as a first-week activity
  3. Send learners to the sandbox to practice safely

Something's broken right now

Go straight to Oh no! Undo any Git mistake. Find your situation and copy the fix.

How each lesson works

  • Read, then do. Every lesson ends with an exercise in your own sandbox repo, never in someone else's project.
  • Quiz. Three questions at the end check what stuck. A perfect score marks the lesson complete.
  • Progress is saved in your browser only. There's no account and no tracking. Your progress bars are on the lessons page.
  • Badges are earned honestly. Read Fair play once before you start. It explains what GitHub's rules allow.

Words you'll meet early

WordMeaning
Repository (repo)A project's folder plus its full history
CommitA saved snapshot of your project, with a message saying why
BranchA separate line of work. It's just a label on a commit
CloneA full copy of a repo on your computer
ForkYour own copy of someone else's repo, on GitHub
Pull request (PR)A request to merge your branch's changes into another branch
MergeCombining the work from one branch into another
IssueA bug report, idea or task, tracked on GitHub

The cheat sheet has the full glossary.
