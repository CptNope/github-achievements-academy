Lesson 8: Highlights & retired badges

Highlights (status badges)

Some badges reflect a status rather than an achievement. They appear in the Highlights area of your profile and can disappear if the status ends.

HighlightHow you get it
PROHave a paid GitHub Pro plan
Developer Program MemberJoin the GitHub Developer Program
Security Bug Bounty HunterHave a valid report accepted through the GitHub Security Bug Bounty
GitHub Campus ExpertBe accepted into GitHub's student leadership program
Security advisory creditBe credited on a reviewed advisory in the GitHub Advisory Database

These change from time to time. If something here is out of date, please open a PR!

Retired or unreleased

You can't earn these anymore, so don't let anyone sell you a "method":

BadgeStatus
Arctic Code Vault ContributorRetired. Tied to repos in the 2020 GitHub Archive Program snapshot.
Mars 2020 Helicopter ContributorRetired. Tied to repos used in the 2021 Ingenuity mission.
Heart On Your SleeveSeen in GitHub's assets, but never released
Open SourcererSeen in GitHub's assets, but never released
